### 🎯 Projectbeschrijving

Voor dit keuzedeel ga ik een mobiele applicatie ontwikkelen waarmee gebruikers eenvoudig een tafel bij een restaurant kunnen reserveren.

De gebruiker kan gerechten bekijken, nieuws lezen en contactgegevens vinden.

### 💡 Waarom dit project?

Tijdens mijn vorige keuzedeel Frontend Verdieping heb ik een restaurantwebsite ontwikkeld met React en JavaScript.

Voor dit keuzedeel wil ik hetzelfde idee gebruiken, maar dan als mobiele applicatie.

Hiermee kan ik mijn kennis uitbreiden en leren werken met React Native.
