# Retro Sprint 1 – Voorbereiding en ontwerp

**Project:** Restaurant Reserveringsapp  
**Keuzedeel:** Mobile Application Development  
**Sprint:** 1  
**Periode:** 10-11-2026 t/m 17-11-2026

---

## 1. Inleiding

Tijdens Sprint 1 heb ik gewerkt aan de voorbereiding en het ontwerp van mijn restaurant-reserveringsapp.

Het doel van deze sprint was om duidelijk te krijgen wat ik wilde bouwen, welke functionaliteiten de app moest krijgen en welke technieken ik zou gebruiken.

Daarnaast ben ik alvast begonnen met het programmeren van de applicatie.

## 2. Wat ging goed?

- Ik heb een duidelijk projectidee gekozen: een mobiele restaurant-reserveringsapp.
- Ik heb de doelgroep en belangrijkste functionaliteiten beschreven.
- Ik heb een Plan van Aanpak opgesteld.
- Ik heb een Trello-board aangemaakt om mijn taken te organiseren.
- Ik heb React Native en Expo ingesteld in VS Code.
- Het is gelukt om mijn app op mijn iPhone te openen met Expo Go.
- Ik heb een Home-scherm en een menukaart gemaakt.
- Ik heb een reserveringsformulier toegevoegd en getest.

## 3. Wat ging minder goed?

Tijdens het werken aan mijn project kwam ik een paar problemen tegen.

- In het begin lukte het niet altijd om de app op mijn iPhone te openen.
- Soms voerde ik terminalcommando's uit vanuit de verkeerde projectmap.
- De knop naar de menukaart werkte eerst niet, omdat de menukaart nog niet aan de navigatie was toegevoegd.
- Ik moest wennen aan de projectstructuur van Expo en de verschillende bestanden.
- Ik heb een paar dagen niet aan het project gewerkt, waardoor ik opnieuw moest bekijken waar ik gebleven was.

## 4. Hoe heb ik de problemen opgelost?

Ik heb de problemen stap voor stap onderzocht en opgelost.

Toen Expo niet goed startte, heb ik gecontroleerd of ik in de juiste projectmap stond en heb ik de app opnieuw gestart.

Bij het probleem met de menukaart heb ik mijn code gecontroleerd. Uiteindelijk bleek dat ik het scherm nog moest toevoegen aan `app-tabs.tsx`.

Ook heb ik geleerd dat ik mijn bestanden moet opslaan en wijzigingen opnieuw moet testen op mijn iPhone.

## 5. Wat heb ik geleerd?

Tijdens deze sprint heb ik geleerd:

- Hoe ik een mobiel project voorbereid met een Plan van Aanpak.
- Hoe ik taken kan organiseren met Trello.
- Hoe ik een React Native-project aanmaak met Expo.
- Hoe ik mijn app op een echte iPhone kan testen met Expo Go.
- Hoe ik schermen maak met React Native.
- Hoe ik navigatie tussen verschillende schermen instel.
- Hoe ik een eenvoudig reserveringsformulier maak.
- Hoe belangrijk het is om fouten stap voor stap te onderzoeken.

## 6. Wat kan ik verbeteren?

In de volgende sprint wil ik:

- Regelmatiger aan mijn project werken.
- Mijn voortgang beter bijhouden in Trello.
- Mijn code na iedere wijziging testen.
- Duidelijk documenteren welke onderdelen ik heb afgerond.
- Meer zelfstandig leren begrijpen waarom bepaalde code werkt.

## 7. Wat neem ik mee naar Sprint 2?

In Sprint 2 ga ik verder met het programmeren van mijn restaurant-reserveringsapp.

De Home-pagina, menukaart en het reserveringsformulier zijn al gemaakt.

Mijn volgende stappen zijn het verbeteren van de invoercontrole van het reserveringsformulier, het toevoegen van nieuwe schermen en het verder testen van de applicatie.

## 8. Conclusie

Ik kijk positief terug op Sprint 1. Ik heb mijn project voorbereid en ben daarnaast al begonnen met programmeren.

Ik ben vooral tevreden dat mijn app op mijn iPhone werkt en dat ik tussen verschillende schermen kan navigeren.

Ik heb ook geleerd dat problemen met Expo en navigatie soms tijd kosten, maar dat ik deze kan oplossen door rustig en stap voor stap te werken.

In de volgende sprint wil ik mijn app verder uitbreiden en mijn werkzaamheden beter plannen.
