# Retrospective – Sprint 2

**Project:** Restaurant-reserveringsapp
**Periode:** 18 november t/m 25 november 2026
**Inleverdatum:** 26 november 2026

## 1. Wat heb ik gedaan?

Tijdens Sprint 2 heb ik verder gewerkt aan het programmeren van mijn restaurant-reserveringsapp. Ik heb React Native en Expo gebruikt om de app te ontwikkelen.

Ik heb de volgende onderdelen gemaakt en verbeterd:

- Het Home-scherm met een restaurantfoto en navigatieknoppen.
- Een menukaart met foto's, prijzen, beschrijvingen en categorieën.
- Een reserveringsformulier met invoercontroles.
- Een kalender en tijdkiezer.
- Plus- en minknoppen voor het aantal personen.
- Een bevestigingsmelding na een geldige reservering.
- Een nieuwsscherm met foto's en aanbiedingen.
- Een contactscherm met contactgegevens en openingstijden.
- Verschillende iconen voor de navigatie.

Ook heb ik de vormgeving verbeterd, zodat alle schermen dezelfde kleuren en stijl hebben.

## 2. Wat ging goed?

Het programmeren ging steeds beter. Ik heb veel nieuwe onderdelen kunnen maken en de app ziet er nu professioneler uit.

Ik heb de app regelmatig getest op mijn iPhone met Expo Go. Hierdoor kon ik snel zien of mijn aanpassingen werkten.

Ik ben tevreden met het resultaat van deze sprint, vooral met de menukaart en het reserveringsformulier.

## 3. Wat ging minder goed?

Tijdens het programmeren kwam ik een paar problemen tegen. Bijvoorbeeld bij de kalender en tijdkiezer was de tekst niet goed zichtbaar op mijn iPhone. Ik heb dit opgelost door de tekstkleur en het thema aan te passen.

Ook moest ik soms de code meerdere keren aanpassen en testen voordat alles goed werkte.

## 4. Waarom heb ik Sprint 2 één dag later ingeleverd?

Ik heb Sprint 2 één dag later ingeleverd, omdat ik op woensdag 25 november moest werken. Mijn werkgever had op dat moment iemand nodig om te werken. Daarom moest ik eerder van school vertrekken om naar mijn werk te gaan.

Hierdoor had ik niet genoeg tijd om mijn documentatie af te ronden en Sprint 2 op tijd in te leveren. Daarom lever ik Sprint 2 op donderdag 26 november in.

Voor de volgende sprint wil ik mijn tijd beter plannen en proberen mijn documentatie eerder af te ronden.

## 5. Wat heb ik geleerd?

Tijdens deze sprint heb ik geleerd:

- Hoe ik schermen maak met React Native.
- Hoe ik tussen verschillende schermen kan navigeren.
- Hoe ik gebruikmaak van `useState`.
- Hoe ik gegevens in een formulier kan controleren.
- Hoe ik gerechten kan filteren op categorie.
- Hoe ik foto's en iconen kan toevoegen.
- Hoe ik problemen kan oplossen door mijn app te testen.


## 6. Conclusie

Ik ben tevreden met mijn voortgang tijdens Sprint 2. De belangrijkste functies van mijn restaurant-reserveringsapp werken en de vormgeving is verbeterd.

De app is op dit moment een prototype. Reserveringen worden nog niet opgeslagen in een database.

Ondanks dat ik deze sprint één dag later heb ingeleverd, heb ik veel geleerd en goede voortgang gemaakt met mijn project.
